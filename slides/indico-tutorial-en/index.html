Indico · Overview

One link for the whole event

Agenda, slides, minutes, video link and calendar entry, all on one page. Indico has three kinds of event:

Meeting

Agenda with times and speakers, slides per item, minutes.

Group meetings, seminars, boards

Lecture

One talk: speaker, abstract, slides.

Colloquia, guest lectures, defences

Conference

Several days, timetable, registration, call for abstracts.

Workshops, schools, conferences

First meeting · Before you start

Three things to know

Log in

Top right of any Indico page. You need to be logged in to create events and upload.

Category

Every event lives in a category, like a folder: school › department › group. Create the event from your group's category page.

Protection

Public, Inheriting (same as the category) or Protected (only listed people and groups).

Minutes often name colleagues. Put internal meeting series in a protected category.

Good to know

Tips

  • Series: create one meeting, then Clone Event every week
  • Titles: leave the date out, since the clones copy it
  • Guests without an account: Enter manually
  • Video link: in the meeting description
  • Calendar: the calendar icon on an event or category page exports it
  • Sensitive minutes or files: protect the event, or the single file
